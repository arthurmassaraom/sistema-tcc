# Referências técnicas externas

Documentação consultada para integrar pagamentos e metadados/capas. O projeto usa o Card Payment Brick para que a entrada do número de cartão, validade e CVV permaneça no componente seguro do Mercado Pago; o backend recebe o token do cartão, calcula o valor a partir do carrinho e usa uma chave de idempotência por pedido. [Mercado Pago — Card Payment Brick](https://www.mercadopago.com.br/developers/pt/docs/checkout-bricks/card-payment-brick/introduction) · [Envio de pagamentos do Card Payment Brick](https://www.mercadopago.com.br/developers/pt/docs/checkout-bricks/card-payment-brick/payment-submission) · [Renderização padrão](https://www.mercadopago.com.br/developers/pt/docs/checkout-bricks/card-payment-brick/default-rendering)

Para PIX, a API de pagamentos retorna um estado de pagamento e os dados `qr_code_base64` e `qr_code`, que representam o QR Code e o código copia-e-cola. O aplicativo não cria uma chave ou QR Code fictício. [Mercado Pago — PIX no Payment Brick](https://www.mercadopago.com.br/developers/pt/docs/checkout-bricks/payment-brick/payment-submission/pix)

O webhook de pagamentos precisa validar `x-signature` e `x-request-id`; o manifest segue o formato documentado `id:<data.id>;request-id:<x-request-id>;ts:<ts>;`, assinado com HMAC-SHA256 e comparado em tempo constante. Após a notificação, o servidor consulta o pagamento à API do Mercado Pago antes de atualizar o pedido. [Mercado Pago — Webhooks](https://www.mercadopago.com.br/developers/pt/docs/your-integrations/notifications/webhooks) · [Notificações opcionais e validação de assinatura](https://www.mercadopago.com.br/developers/pt/docs/checkout-api-orders/optional-notifications)

O Google Books API disponibiliza pesquisa pública de volumes e os campos `volumeInfo.imageLinks` (`thumbnail`, `small`, entre outros). Capas podem variar ou não estar disponíveis para todas as edições/países; o acervo do projeto mantém os arquivos de capa referenciados em seus registros locais. [Google Books API — volumes](https://developers.google.com/books/docs/v1/reference/volumes) · [Google Books API — uso e busca](https://developers.google.com/books/docs/v1/using)
